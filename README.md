# Power_BI_Project

Turning a 40M-row election results dataset into a story you can actually see. 📊

For this project, I built an interactive Power BI dashboard analyzing a recent national presidential election — covering vote counts, turnout, and regional patterns across dozens of administrative districts.

What went into it: 🔹 Sourced raw results data and cleaned it in Power Query — standardizing region names, handling missing values, and fixing data types 🔹 Built DAX measures for turnout %, valid vote %, and vote share by candidate 🔹 Designed an interactive map visual with drill-through by district, cross-filtering slicers, and dynamic result cards 🔹 Uncovered a historic first-ever second-preference count that decided the final outcome 🔹 Found sharp regional divides in turnout and vote share that the national-level numbers alone didn't show

The biggest takeaway for me: national summary numbers can hide very different local stories. Interactive dashboards let you go from "what happened" to "where and why" in just a few clicks.
